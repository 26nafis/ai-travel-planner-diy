# Lampah Jogja design system

## Genre
Modern-minimal with an editorial travel-planning tone.

## Page families
- Marketing: a split field guide hero with the product map as the main visual.
- App: a focused planning workspace; controls and itinerary remain the primary content.
- Content: a readable single-column flow with compact section labels.

## Theme
- Warm off-white canvas, white panels, deep ink, muted blue-gray rules.
- Keep Lampah Jogja's blue as the navigation and map accent; use orange only for primary actions and selected highlights.
- Typography: Plus Jakarta Sans, with regular upright headings and a restrained weight range.
- Spacing: 4-point rhythm; compact form controls, larger section gaps.
- Motion: brief state transitions only; respect reduced-motion preferences.
- CTA voice: rounded rectangular, high-contrast primary action; quiet outlined secondary action.

## Shared rules
- Keep the Kawung mark and Lampah Jogja name.
- Use the same blue/orange tokens, control shapes, focus ring, and type family on every route.
- Prefer map, itinerary, and destination content over decorative illustrations or unsupported statistics.
- Mobile layouts stack naturally; map controls remain reachable without horizontal scrolling.
